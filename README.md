## Cómo está organizado

Cada tema contiene una carpeta por ejercicio. Se mantienen los nombres y todos los archivos originales, incluidos los recursos de cada web.

## Historial y conservación

La importación conserva los commits originales con sus autores, fechas e identificadores. Cada incorporación conecta ese historial con la rama `main`. Las ramas originales se guardan bajo `originales/<repositorio>/<rama>` y las etiquetas bajo `originales/<repositorio>/<etiqueta>`.

El archivo `migracion.json` registra el origen, el commit y el árbol de archivos de cada importación. Los árboles importados se han comparado con los originales para verificar que coinciden exactamente.

Los repositorios originales tienen GitHub Pages activado. Los enlaces anteriores corresponden a sus direcciones habituales; no se ha trasladado su configuración de publicación a este repositorio ni se ha comprobado que cada web esté disponible. Para abrir los ejercicios desde esta copia, usa su archivo HTML de entrada; algunos ejercicios pueden necesitar un servidor local para cargar JSON.

## Organización para próximas asignaturas

- Un repositorio por asignatura y curso, por ejemplo `programacion-2-dam-2026-2027`.
- Una carpeta por tema y otra por ejercicio dentro de cada tema.
- Mantener un índice en el README y un `.gitignore` adecuado al lenguaje.
- Dar repositorio propio a proyectos grandes, trabajos en grupo o entregas que lo exijan.
- Usar ramas para cambios y pruebas, manteniendo los temas en carpetas.
