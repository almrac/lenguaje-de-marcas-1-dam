01. JSON cliente

Enunciado

Consumir un archivo JSON de un cliente con fetch y mostrar sus valores mediante alert, incluyendo un objeto direccion y un array de aficiones.

Que hace este ejercicio

Al pulsar el botón, JavaScript leerá el archivo miCliente.json con fetch y mostrará sus datos mediante varias ventanas alert.

  • Datos básicos del cliente
  • Datos del objeto direccion
  • Valores del array aficiones

Pulsa el botón para cargar el JSON y ver los alert.
